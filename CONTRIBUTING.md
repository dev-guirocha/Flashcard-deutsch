# Contributing

Small and focused pull requests are preferred.

## What is welcome
- Bug fixes
- Accessibility improvements
- New tests
- Deck/content improvements with clear licensing

## Deck/content rules
Every deck contribution must include:
- `source` (origin project/dataset)
- `license` (compatible with repository policy)
- attribution text when required

Update `data/SOURCES.md` for every new or changed deck.

## Pull request flow
1. Fork repository
2. Create branch (`feat/...` or `fix/...`)
3. Add tests for behavior changes
4. Open PR with before/after summary
